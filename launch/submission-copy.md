# VibeCoding 大赏投稿文案

## 标题

VibeCoding大赏｜我给 DeepSeek 做了一个免费识图 Skill

## 一句话

Free Vision Skill 让没有原生视觉能力的文本模型，在需要时通过免费视觉 API 获得低 Token 的图片理解能力。

## 项目亮点

1. 视觉模型只负责看见，主模型继续思考
2. 图片被压缩成极简 VEP，而不是长描述
3. 支持截图、UI、报错、OCR 和图表
4. 多个免费 / 免费层视觉 Provider
5. 相同图片与问题可本地缓存，避免重复消耗额度
6. 支持 OS Keychain，减少 API Key 暴露风险

# GitHub Release v0.1.0

## Free Vision Skill is here 👁️

A low-token visual evidence compiler for text-only coding agents.

### Highlights

- Focused screenshot / UI / OCR / chart understanding
- VEP/1 compact visual evidence protocol
- Multiple legitimate free/free-tier providers
- Region-aware fallback
- Local SHA-256 result cache
- `.env` BYOK
- macOS and Linux Keychain support
- Agent Skill instructions for Codex, Claude Code and OpenCode

### Install

```bash
git clone https://github.com/lora-sys/free-vision-skill
cd free-vision-skill
npm install
npm run check
```

### Philosophy

> Vision models see. Main models think.

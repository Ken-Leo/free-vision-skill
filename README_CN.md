## 核心特性

- 🎯 **低 Token 消耗** — 默认 50-220 tokens
- 🔄 **自动降级** — Provider 限流自动切换
- 💾 **本地缓存** — SHA-256 缓存
- 🔐 **安全存储** — Keychain 支持
- 🌍 **13 个 Provider** — 国内 4 + 全球 9
- 📦 **易于集成** — `npx skills add` 一键安装

# Security Policy

Do not publish API keys, private screenshots or internal repository data in an issue.

For vulnerabilities, use GitHub Security Advisories after the repository is published.

Supported security features:

- environment-variable credentials
- macOS Keychain
- Linux Secret Service
- VEP-only main-model context
- local result cache
- no anonymous proxy registry entries

See `docs/SECURITY.md` for the threat model.
